#  The Write Blueprint
## The blog app for entrepreneurs, to share their exprience everywhere.

This app is built as a blog app for entrepreneurs to share their stories, using Flutter framwork and Supabase DB in Clean Architecture.

### In this app: 
- Flutter will be used as front & backend **(later on it will be moved to a backend in NodeJS or Serverpod)**.
- Bloc is the state management platform of choice.
- Supabase will be used for the database using PostgreSQL.
- Billing using Stripe APIs

## APP FEATURES:
### Authentication
- User signup (email/password) 
- User signin (email/password)
- Email verification
- Password Change
- Password Reset
### Blog
- Create a blog post (Markup, Images, Links, GIFs
- See other blogs posted
- Edit blog posts
- Delete blog posts
- Like, Save, Comment on blogs
- Follow Other bloggers.
### Search
- Search for blog posts
- Search for topics of blog posts
- Search for other users
### Notifications
- Notifications for people you follow
- Notifications for topics you follow
- Notifications for recommendations
- Notifications for likes, comments, saves on your blogs
### Profile
- Edit user profile
- See posted blogs
- See scheduled blogs
- See your followers/followings
- See your settings
### Saved
- See posts your saved
- Create reading lists
### Premium Subscription
- User billing (monthly sub fee for premium users using stripe api)
- Verified badge
- "Biggest editors" on the app

### Approach to development (Abilities deomnstrated)
Clean architecture will be used for single responsibility and separation for concerns to ensure rapid and tight development.
Integration with other APIs like Stripe
CI/CD into github 
Version control with GIT
Full stack development/Code reformating and scaling (when the backend is integrated)
